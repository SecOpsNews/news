# Security Policy

This policy covers the SecOpsNews site (<https://secops.thechels.uk>) and this repository.

## Reporting a vulnerability

Please report security issues privately, either:

- by email to [secops@thechels.uk](mailto:secops@thechels.uk), or
- through [GitHub private vulnerability reporting](https://github.com/SecOpsNews/news/security/advisories/new).

Please don't open a public issue for a vulnerability.

Headlines on the site link to third-party articles. Issues with those sites should be reported to their owners.

Contact details are also published at <https://secops.thechels.uk/.well-known/security.txt>.
